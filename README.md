# CodeAlpha-PowerBI-Tasks
# HR Analytics Dashboard

# Project Overview
This project presents an interactive Human Resources Analytics dashboard developed using Microsoft Power BI.

# Objectives
- Analyze employee turnover
- Analyze employee satisfaction and performance
- Evaluate recruitment metrics
- Analyze recruitment sources and hiring pipeline
- Forecast future hiring needs

# Dashboard Pages

## 1. Employee Overview
- Total Employees
- Active Employees
- Employee Turnover
- Satisfaction Analysis
- Performance Analysis
- Department-wise Analysis

## 2. Recruitment & Hiring
- Total Candidates
- Hired Candidates
- Hiring Rate
- Average Days to Hire
- Recruitment Pipeline
- Recruitment Source Analysis
- Actual vs Forecast Hiring Needs

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
